### 1.1 核心使命與業務界限
* **智財主權在民**：平台本身**不訓練通用模型、不收存明文知識包**。我們協助專家利用地端硬體（FHE AI NAS）與實體 USB 安全密鑰，將其畢生絕活轉化為可受控授權、不可否認計量的「數位分身（Digital Twin）」。
* **消除 AI 取代恐懼**：斜槓 123 不是淘汰人類的工具，而是讓個人能力透過數位分身 24 小時為全球提供推理服務，形成源源不絕的智慧被動收益。
* **雙向躍升梯隊**：使用者在「斜槓 123」累積可驗證之專家評價與能力收據後，可平滑升級對接至「斜槓 104」企業級高階顧問智庫。

## 2. CIS 企業形象識別規範 (Corporate Identity System)

本儲存庫為斜槓 123 視覺與精神識別之最高真理基準（Single Source of Truth），所有行銷物、事務印刷品、社群資產皆須嚴格溯源本規範。

### 2.1 MI (Mind Identity) 理念識別
* **公司全稱**：斜槓一二三科技股份有限公司 / Slash 123 Inc.
* **品牌主張 (Slogans)**：
  * **主標語**：*智財自主，分身有術。*
  * **副標語**：*在 AI 時代，讓你的專業為你工作，而不是替平台打工。*
  * **英文 Slogan**：*Empowering Sovereign Talents, Multiplying Your Impact.*
* **品牌基調 (Brand Personality)**：
  * **敏捷躍動 (Agile & Dynamic)**：跳脫傳統顧問產業的沉悶，展現年輕、多職能與跨界生機。
  * **堅毅護衛 (Secure & Sovereign)**：具備背靠 AEGIS 密碼學技術的底層信賴感。
  * **平易近人 (Accessible & Clear)**：拒絕高冷技術黑話，用直白易懂的語言賦能廣大工作者。

### 2.2 VI (Visual Identity) 視覺識別

#### A. 核心標誌幾何構成 (Logo Geometry)
標誌由三大符號交織構成：
1. **躍進斜槓（Dynamic Slash `／`）**：呈現 $45^\circ$ 上升仰角，象徵打破職涯天花板與身分藩籬。
2. **階梯式三聯方塊（1-2-3 Tri-Nodes）**：沿著斜槓躍升的三個幾何光點，分別代表「本體技能 (1)」、「數位分身 (2)」、「三倍收益 (3)」。
3. **量子環流邊界（Encrypted Orbital）**：微細之同態運算環流圍繞節點，暗喻硬體金鑰守護之知識邊界。

#### B. 品牌標準色票 (Brand Color Palette)

## 7. 部署策略與安全不變量 (Deployment & Security Invariants)

1. **嚴禁將 GitHub Pages 作為正式商業入口**：
   * GitHub Pages 僅限用於內部 UI Review 與 Design System 預覽。
   * 正式營運路徑：
     $$\text{GitHub Repo} \xrightarrow{\text{GitHub Actions CI/CD}} \text{Azure Static Web Apps} \xrightarrow{\text{Custom Domain (slash123.com)}}$$
2. **交易與敏感個資嚴格隔離**：
   * 本形象官網**不暫存任何信用卡資訊、不儲存會員私鑰、不提供明文知識庫下載**。
   * 所有涉及授權交易之行為，皆透過安全權限閘道（Rights Gateway）分流至專屬合規端點。
